# Six-layer token lineage

RAW → ATOMIC → PRIMITIVE → SEMANTIC → COMPONENT → COMPOSITION

Every token requires:

- token ID
- layer
- value/type
- source evidence IDs
- selector/origin when applicable
- viewport/state when applicable
- deterministic transformation description
- status
- supersedes/supersededBy when applicable

No orphan tokens. No silent contradiction merge. Mapping is not provenance.
