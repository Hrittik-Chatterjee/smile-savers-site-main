# AI Design & Execution Knowledge Pack v1.1.0

Evidence-first, agent-neutral knowledge and execution-capture foundation for Claude Code and other coding agents.

Core doctrine:

- Research explains.
- Evidence proves.
- Decisions constrain.
- Artifacts reproduce.
- Mappings never become provenance.
- Hidden model chain-of-thought is never reconstructed or claimed.

This pack contains current external grounding plus schemas, prompts, cache rules, capture design, and adversarial tests. Private Claude transcripts, the actual Labs mirror, and Smile Savers repository artifacts are intentionally not fabricated into this pack; import those as separately hashed evidence objects.
